# 《荒》二次元 V1 歌词字幕版设计

## 目标

为任务 `189998` 的二次元母带 `Seedance2.5_荒_渠道Y_任务189998_母带成片.mp4` 增加歌词字幕，生成独立字幕版，不覆盖现有无字幕母带。

## 时间基准

30 秒母带由 4.00 秒纯音乐前奏、21.68698 秒原歌曲片段和 4.31302 秒纯音乐尾奏组成。原歌曲歌词 SRT 以歌曲片段 0 秒为起点，因此烧录时间统一后移 4.00 秒。

| 母带时间 | 歌词 |
|---|---|
| 04.00–07.18 | 一念间天荒仙灭 |
| 07.18–09.30 | 我仍立八荒间 |
| 09.30–13.46 | 踏碎林霄又葬下了天 |
| 14.06–17.14 | 我欲横剑天啸 |
| 17.14–19.80 | 此去沧海落扶摇 |
| 20.18–23.48 | 万古梦回涅槃何道 |

前奏、句间空白和尾奏不显示字幕。歌词保留已有高清画面字幕与 ASR 交叉核对结果；其中“林霄”“何道”不擅自改为未经证实的常见写法。

## 字幕视觉

- 竖屏底部居中，距离底边约 150 像素，位于短视频平台安全区内。
- 单行冷调浅蓝白中文宋体（RGB `#E2EEF3`，ASS `&H00F3EEE2`），暗青黑描边与轻阴影；此颜色经用户审阅后批准。
- 字幕宽度限制在画面安全区，不遮挡人物脸部或关键手部动作。
- 不使用卡拉 OK 逐字变色、不加标题、不加对白、不加 Logo。

## 输出

- `荒_V1_歌词字幕.ass`：可编辑字幕源文件。
- `Seedance2.5_荒_渠道Y_任务189998_母带歌词字幕版.mp4`：烧录字幕成片。
- `任务189998_歌词字幕版_审片联系表.jpg`：覆盖全部六句歌词和无字幕首尾的抽帧证据。
- `字幕生成记录_任务189998.md`：字体、时间轴来源、媒体规格、哈希与验收结论。

## 验收

- 六句歌词各出现一次，时间连续关系正确，无前奏误显示和尾奏残留。
- 字幕无缺字、乱码、越界、截断或明显遮挡人物面部。
- 成片完整解码；视频保持 720×1280，音频保持 AAC 48 kHz 双声道，总时长 30.000 秒。
- 原无字幕母带保持不变。
